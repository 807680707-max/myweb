两端数字：24h 最低价 / 最高价

圆点 靠左(绿) = 接近 24h 低点 → 买入窗口

数据来源
24h 最低/最高价 = 过去 24 小时 API 数据中的 min/max
当前价 = 最新一次 API 返回的价格
圆点位置 = (当前价 - 最低) / (最高 - 最低) × 100%

如果数据点不足 24h (首次打开)，则用已有数据计算区间
