# 三角洲行动交易辅助工具 — 设计文档

## 概述

一个基于 Web 的《三角洲行动》交易辅助工具，帮助玩家通过倒卖子弹/物品赚取哈夫币。核心功能：行情监控、买卖建议、盈亏追踪、事件日历、AI 分析。

## 技术选型

- **前端**：单页 HTML + Vanilla JavaScript + ECharts
- **数据源**：delta-force-api / DeltaForcePrice，每 10 分钟更新
- **存储**：localStorage（持久化）+ JSON 导出/导入
- **部署**：Cloudflare Pages / Vercel，零成本
- **无后端**：纯前端，直连第三方 API

## 页面结构

单页面，顶部 Tab 切换，共 5 个模块：

### Tab 1：行情看板

**顶部栏**：数据新鲜度（"X 分钟前更新"）、搜索框、分类下拉、手动刷新按钮

**统计卡片（4 个）**：总物品数、今日涨幅 Top、今日跌幅 Top、异常波动数

**价格表格**：
- 列：物品名（按品质着色）、分类、当前价、24h 最低、24h 最高、涨跌幅（红绿）、详情
- 排序：点击任意列头排序
- 筛选：分类下拉（弹药/钥匙卡/配件/装备/全部）
- 收藏：星标置顶

**详情面板**（点击某物品后展开）：
- ECharts 价格走势折线图，X 轴=时间，Y 轴=价格
- 图上标记：最高点/最低点（价格+时间）、异常波动点、事件标注竖线
- 可切换时间范围：24h / 7d / 30d

**品质颜色映射**：

| 等级 | 颜色 | 色值 |
|------|------|------|
| 1 级 | 白色 | `#c0c0c0` |
| 2 级 | 绿色 | `#4ade80` |
| 3 级 | 蓝色 | `#3b82f6` |
| 4 级 | 紫色 | `#a855f7` |
| 5 级 | 金色 | `#f4a261` |
| 6 级 | 红色 | `#ff4d5a` |

物品名后附带品质标签（如 "5级 金弹"），所有 Tab 统一应用。

### Tab 2：买卖建议

**顶部概览卡片**：建议买入数、建议卖出数、当前持仓总盈利

**交易信号表**：
- 列：物品名（品质色）、当前价、24h 均线、24h 走势（sparkline）、偏离百分比、信号标签、置信度
- 走势图：SVG sparkline（260x80），X 轴时间刻度（08:00/12:00/16:00/20:00/现在），Y 轴价格刻度，最高最低点标记+时间，走势线颜色（绿=跌/红=涨/黄=震荡），虚线=当前价水平，渐变填充

**信号逻辑**：
- 价格偏离 24h 均线超过阈值 → 触发信号
- 低于均线 N% → 买入信号
- 高于均线 N% → 卖出信号
- 偏离不足 → 观望
- 置信度基于：偏离幅度、趋势一致性、连续周期数
- 税费纳入：卖出建议需要标价×87% > 成本 才触发

**提醒设置栏**：阈值 % 可调（默认 15%）、买入/卖出提醒开关

### Tab 3：盈亏追踪

**税费设置栏**（重要）：
- 保证金比例（默认 3%，可调）
- 手续费比例（默认 10%，可调）
- 税费计算：税后到手 = 卖出标价 × (1 - 保证金% - 手续费%)
- 税后盈亏 = (税后到手 × 数量) - (买入均价 × 数量)
- 盈亏平衡提醒：标价需高于买入价约 15% 才能回本

**顶部概览卡片**：持仓物品数、总成本、当前市值、税后浮盈（金额+百分比）

**当前持仓表**：
- 列：物品（品质色）、持有量、买入均价、成本、卖出标价、税后到手、税后盈亏（红绿色）
- 加权均价：多次买入自动合并计算
- 操作按钮：记录买入 / 记录卖出

**交易记录表**：
- 列：时间、类型（买入绿/卖出红）、物品、数量、单价、总价、盈亏
- 数据：localStorage 持久化
- 自动清理：超过 30 天的已完成交易记录

**数据管理**：导出 JSON / 导入 JSON，手动备份恢复

### Tab 4：事件日历

月视图日历，标注影响价格的事件。

**事件类型**：版本更新、赛季更替、节假日活动、武器调整、官方补货、其他

**事件属性**：
- 日期/时间、标题、类型、影响描述
- 影响预测：预期涨/跌 + 幅度范围（如"预期弹药涨 10-20%"）
- 关联物品：可指定影响的物品分类或具体物品

**日历视图**：
- 蓝色标记 = 已发生事件
- 橙色标记 = 即将发生事件
- 点击日期展开当日事件列表
- 月/周切换

**与走势图联动**：
- 事件自动出现在行情看板的走势图上（竖线标记）
- 事后可以标注"预测准确/不准确"，统计预测准确率

### Tab 5：AI 分析

**AI 对话面板**：
- 聊天界面，可配置 API Key（支持 DeepSeek / Claude 等）
- AI 自动注入上下文：当前行情数据、持仓、走势图摘要、最近事件
- 典型问题："金弹现在该不该入？""哪种子弹最适合抄底？""帮我看看持仓哪些该卖了"
- API Key 存储在 localStorage，不经过任何服务器

**分析报告导出**：
- 一键生成文本摘要：行情概况 + 价格走势 + 持仓盈亏 + 异常信号 + 近期事件
- 可粘贴到 AI 对话中分析（无需 API Key 的替代方案）

## 数据流

```
DeltaForcePrice (上游) → delta-force-api (HTTP JSON) → 前端 fetch()
                                                          ├→ 内存缓存（最新价格）
                                                          ├→ ECharts 渲染走势图
                                                          ├→ localStorage（交易/持仓/事件/配置）
                                                          └→ AI 上下文注入
```

## 数据存储

**localStorage 键值设计**：
- `df_trades` — 交易记录数组
- `df_holdings` — 当前持仓数组
- `df_events` — 事件日历数组
- `df_config` — 配置（税率、刷新间隔、提醒阈值、API Key）
- `df_price_history` — 本地缓存的历史价格（补充 API 可能不返回的历史数据）

**数据清理策略**：
- 交易记录：已完成且超过 30 天的自动删除
- 价格历史：保留最近 90 天，滚动清理
- 用户手动导出 JSON 备份

## 自动刷新

- 每 10 分钟自动 fetch 最新价格
- 页面显示"数据更新于 X 分钟前"
- 手动刷新按钮可提前触发
- 刷新时仅更新变化的数据，表格不闪烁

## 异常检测

- 单次涨跌幅超过 15%（可配置）→ 标记"异常波动"
- 连续 3+ 周期同向涨跌 → 标记"趋势加速"
- 异常标记出现在走势图和事件日历中

## 税费计算（重要）

- 默认：保证金 3% + 手续费 10% = 综合 13%
- 税率高度可配置，用户根据游戏内实测校准
- 所有盈亏计算均使用税后到手价
- 买卖信号也纳入税费校验
- 如果 API 返回物品"原价"字段，可实现分段精确计算（v2）

## 文件结构

```
myweb/                         # 项目根目录
├── index.html                 # 主页面（所有 Tab + 逻辑）
├── data/                      # 如果 API 需要兜底，放本地映射数据
│   └── items.json             # 物品-等级-分类 映射表（API 不返回时兜底）
├── works/                     # 已有文件
├── docs/superpowers/specs/    # 设计文档
└── .superpowers/brainstorm/   # 头脑风暴产物
```

单文件 `index.html` 包含所有 CSS + JS + HTML，不依赖构建工具。

## 不考虑的内容（v1 范围外）

- 用户登录/注册
- 后端服务器/数据库
- 游戏客户端操作（OCR/鼠标模拟）
- 多设备同步（可通过 JSON 导入导出手动实现）
- 自动抓取官方公告
- 社区舆情分析
